Stat weights BalancedView / edit weights ⌄

Edit points per 1 stat (or per 1% for percentage stats) to two decimal places. Changes recalculate rankings immediately and are saved in this browser.

Score = stat amount × editable profile weight. These are comparison weights, not predicted damage or mitigation. All weights can be set to 0.00. Weapon DPS is scored; speed is displayed with a default weight of zero because its value depends on mechanics. Procs, on-use effects, and set bonuses still require separate judgment. Do not equate ratings with percentages.
